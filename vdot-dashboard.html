Project overview

The Maintenance Rating Program (MRP) Dashboard is a centralized view for VDOT managers to prioritize work, and spot blockers early. It brings booking status, inspection results, and location context into one place so teams can move from signal to action faster.

Goals

  • Give district managers a single place to triage and assign work.
  • Surface real-time status.
  • Reduce manual data pulls across systems.
  • Improve communication paths between field and office.

Key features

  • Worklist clear states and due-soon highlights.
  • Role-aware panels: views tailored for ops leads and coordinators.
  • Interactive map context: location and cluster signals for routing.
  • Notification stream: centralized updates with deep links.
  • Accessible UI: WCAG-aligned contrast and spacing for long sessions.

Competitive analysis

What we borrowed—and what we improved for MRP:

  • At-a-glance dashboards help users prioritize; we added color.
  • Maps in context are powerful; we balanced map size with actionable tables.
  • Notifications reduce inbox hopping; ours deep-link into the exact record and filter state.
