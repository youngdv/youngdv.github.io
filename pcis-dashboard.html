Project overview

The Port Community Information Sharing (PCIS) Proof of Concept is a multi-persona desktop interface designed to streamline port coordination by improving shared visibility across key stakeholder roles. The experience provides tailored dashboards for Terminal Operators, Transportation Operators, and Beneficial Cargo Owners (BCOs) to support appointment-style scheduling, container status tracking, and cross-stakeholder communication.

This project explored how a unified view of cargo and operational signals can reduce manual follow-ups, improve alignment around capacity and timing, and help ports without a single system operate more efficiently.

Goals

  • Improve cargo visibility across roles with consistent, role-based dashboards.
  • Support appointment and pickup workflows with real-time status and clear next steps.
  • Reduce coordination overhead by centralizing updates, approvals, and notifications.
  • Enable faster operational decisions by surfacing priority items and live signals.

Competitive analysis

Design implications for PCIS

  • Add a concise “Today / Now” section to each persona dashboard with prioritized items and quick actions.
  • Pair worklists with live signals that inform scheduling and timing decisions.
  • Maintain consistent navigation across personas while tailoring KPIs and terminology per role.
  • Standardize problem → cause → fix patterns for errors, validation, and exceptions.
  • Use a unified notifications panel with filters and deep links to records.

UI elements

Role-based dashboards were designed to keep navigation consistent while adapting metrics, terminology, and actions to each stakeholder’s responsibilities.

Terminal Operator Dashboard

Review and approve bookings, monitor terminal activity, and manage container status updates.

Transportation Operator Dashboard

Track assigned pickups, confirm readiness, and update milestone status as work progresses.

BCO Dashboard

Monitor container location and status, view timelines, and communicate updates across partners.

Usability testing & validation

To evaluate the proof of concept, a task-based usability test was conducted with representative port stakeholders. While the effort was labeled as “UAT” in project materials, the sessions were structured as usability testing focused on task completion, clarity of terminology, and overall ease of use across roles.

  • Helped define task scenarios aligned to each persona’s workflows and responsibilities
  • Served as note-taker during sessions and captured both usability issues and user expectations
  • Collected quantitative ratings alongside qualitative feedback during remote walkthroughs
  • Organized open-ended feedback into themes to identify patterns across stakeholder roles

Participants described the experience as easy to use and intuitive, and the themed synthesis helped prioritize improvement areas such as terminology alignment, workflow visibility, and flexibility for different operational contexts.

Outcomes

  • Usability testing feedback indicated the system was easy to understand and intuitive to use across roles
  • Synthesized qualitative feedback into themes to highlight recurring needs and usability patterns
  • Translated themed findings into recommendations to support future iterations and expanded scope
  • Built strong stakeholder alignment on core dashboard structure, terminology, and proof of concept direction
